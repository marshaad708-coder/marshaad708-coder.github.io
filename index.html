VisionAI — Defect Detection for Smart Manufacturing

An end-to-end visual inspection system for factory surfaces, combining supervised classification with unsupervised anomaly detection in one Flask dashboard.

  • Track A: a 6-class CNN trained from scratch on the NEU-CLS steel-surface dataset, with Grad-CAM overlays that show exactly where the model is looking.
  • Track B: PatchCore anomaly detection on MVTec AD — image AUROC 0.917, pixel AUROC 0.927 — flagging defects it was never trained on.
  • Both tracks evaluated on held-out test splits and served through an interactive web dashboard.

ForgeAD — Learning Defects Without Defects

An independent re-implementation of CutPaste (CVPR 2021): the model learns what "normal" looks like by inventing its own defects, so it needs zero labelled anomalies.

  • Synthetic defects are generated by cut-paste augmentation plus scar synthesis on normal MVTec toothbrush images only.
  • A ResNet-18 three-way classifier with Gaussian density scoring reaches pixel AUROC 0.914 — within 1.3 points of a memory-bank PatchCore baseline.
  • The full report includes an honest analysis of where self-supervision wins and where it falls behind.

Roman Urdu Toolkit — NLP for an Underserved Language

Millions write Urdu in Latin script every day, yet almost no NLP tooling exists for it. This Python package is a complete, tested starter toolkit for the language.

  • Normalization and Roman Urdu → Urdu script transliteration driven by a curated 200+ word lexicon.
  • Lexicon sentiment analysis with negation handling, plus edit-distance spellchecking for noisy social-media text.
  • Ships with a CLI, Flask demos and a test suite — the engine that later powered LingoWorld's Roman Urdu mode.
